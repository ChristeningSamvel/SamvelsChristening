# Birthday Invitation Website

Это готовый статический сайт. Его можно опубликовать на GitHub Pages, Netlify, Vercel или другом хостинге.

## Что изменить
Open `index.html` and replace:
- `[ИМЯ ИМЕНИННИКА]`
- `[ДАТА]`
- `[ВРЕМЯ]`

Photos are in the folder `images`. Замените:
- `photo1.jpg`
- `photo2.jpg`
- `photo3.jpg`

The Google Maps link is already included.

## Important: RSVP form
The form currently works in the browser and saves the data locally. To receive real guest responses (for example, in Google Sheets or by email), connect the form to a service such as Formspree, Google Apps Script, or a backend.

## Publishing
The easiest option is to upload the whole folder to Netlify Drop or GitHub Pages.
